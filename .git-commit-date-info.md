# Git Commit Date Guide

## How to Make Commits with Tomorrow's Date

### Method 1: Using --date flag (Easiest)
```bash
git commit --date='2026-01-02 12:00:00' -m 'Your commit message'
```

### Method 2: Using Environment Variables
```bash
export GIT_AUTHOR_DATE='2026-01-02 12:00:00'
export GIT_COMMITTER_DATE='2026-01-02 12:00:00'
git commit -m 'Your commit message'
```

### Method 3: Amend Existing Commits
```bash
git commit --amend --date='2026-01-02 12:00:00' --no-edit
```

## Date Format Options
- `2026-01-02` (date only)
- `2026-01-02 12:00:00` (date and time)
- `2026-01-02T12:00:00` (ISO format)
